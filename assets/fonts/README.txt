Agenda web fonts
================
Agenda is a commercially licensed typeface, so it is not included here.
To use it on the website, add licensed web font files to this folder
with these exact names:

  Agenda-Regular.woff2
  Agenda-Medium.woff2
  Agenda-Bold.woff2

Until they are added, the site uses Agenda if it is installed on the
visitor's computer, and otherwise falls back to Fira Sans.
